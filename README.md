# staj-calismalar-
Bilgisayar Programcılığı staj sürecinde öğrendiğim WordPress, GitHub, SEO ve web geliştirme çalışmalarını içeren proje deposu.

## Öğrendiğim Konular

- Git ve GitHub Temelleri
- WordPress Yönetimi
- Elementor Kullanımı
- SEO Optimizasyonu
- HTML ve CSS Temelleri
- Web Sitesi İçerik Yönetimi
- Domain ve Hosting İşlemleri

## Yapılan Çalışmalar

- Kişisel web sitesi geliştirme
- Blog içerikleri hazırlama
- SEO düzenlemeleri
- Öğrenci kayıt sistemleri üzerinde çalışma
- Web sitesi güncelleme ve bakım işlemleri

## Hedeflerim

- Yazılım geliştirme alanında kendimi geliştirmek
- Açık kaynak projelere katkı sağlamak
- GitHub üzerinde portföy oluşturmak
